## 🔧 Troubleshooting

### The file does not open

Make sure you extracted the ZIP file first. Double-clicking a ZIP file only opens the archive. You must right-click and choose **Extract All**.

### The tool looks broken

Your browser may block some features. Try this:

1. Right-click the `.html` file.
2. Select **Open with**.
3. Choose your browser (Chrome, Edge, or Firefox).

### The page says "This file is not safe"

This happens because the file is from the internet. To fix this:

1. Right-click the `.html` file.
2. Select **Properties**.
3. Check the box that says **Unblock**.
4. Click **OK**.
5. Open the file again.
